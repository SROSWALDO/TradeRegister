# Palacios Logistics - Freelance

Desarrollo de una plataforma **Full-Stack** diseñada para optimizar la gestión de mercancías y mejorar los flujos operativos dentro de la empresa Palacios Logistics.

## Funcionalidades
- **Registro de datos:** Almacena y gestiona la información relacionada con la mercancía de manera eficiente.
- **Envío de datos por correo electrónico:** Automatización del envío de información relevante por email.
- **Generación de reportes en PDF:** Creación automatizada de informes detallados en formato PDF para facilitar el seguimiento y análisis de datos.

## Tecnologías utilizadas
- **Frontend:** NextJS, TailwindCSS.
- **Backend:** PostgreSQL.

Este proyecto fue diseñado para optimizar los procesos operativos de Palacios Logistics, ofreciendo una plataforma robusta
